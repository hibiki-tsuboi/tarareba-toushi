## 取得と照合

`npm run fetch:mufg` は公式商品ページから案内される設定来CSVを取得します。CSVの参照先は公式の `/fund_xml/setteirai/<ファンドコード>.xml` でも確認できます。公開APIは1日単位のため、全履歴の構築には一括CSVを使います。

最新情報は `https://developer.am.mufg.jp/fund_information_latest/association_fund_cd/<投信協会コード>` で取得します。CSV最終日とAPI基準日、通常の基準価額が一致することを確認します。更新の途中でCSVとAPIがずれた場合は、新版を出力せずに終了します。2商品とも成功してからファイルを書きます。

通信はHTTPS・リダイレクト拒否・20秒タイムアウト・応答上限2MiBです。1回につきCSV2回とAPI2回を直列に取得し、データの異常やHTTPエラーを休日扱いで無視しません。日次ジョブでは失敗時に60秒間隔で最大3回試します。

## 系列の意味

CSVはShift_JISで、日付、通常の基準価額、分配金再投資の基準価額、税引前分配金、純資産総額を含みます。採用するのは**基準価額（分配金再投資）**の列です。公式ページの注記に従い、税引前分配金を再投資し、信託報酬を控除した値として扱います。分配金を足し直したり、信託報酬を再控除したりしません。

日付は `YYYY-MM-DD`、値は10進数文字列に変換します。丸め直し、欠測日の補間、株価指数や他商品の接ぎ足しはしません。アプリは2商品の共通観測日だけで比較します。計算方法は [データ形式](data-format.md) を参照してください。

## 配信とアプリ

生成先は `public/live/` のみで、iOSアプリには価格データを同梱しません。内容が変わるとハッシュを含む新しい版を作り、同じ内容なら版と作成日時を保持します。履歴ファイルを先に書き、manifestを最後に切り替えます。`npm run validate` でスキーマ・値・日付・商品・共通期間を確認してから公開します。

通常起動は実データモードです。新規インストール直後は価格データがなく、初回にCloudflareから2商品を取得・検証・保存してから表示します。初回取得に失敗した場合は結果を表示せず、再試行を案内します。取得済みならオフラインでも保存データを利用でき、更新失敗時も保持します。画面と説明に出典を記載し、商品ページへのリンクを設けています。

今回の取得では2026-09-04までのオルカン1,913観測、S&P500 1,995観測を確認しました。最新の通常基準価額はそれぞれ37,945円、44,392円で、CSVとAPIが一致しています。
